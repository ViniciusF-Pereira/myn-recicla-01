# Myn API Demo — Storylines

Assunção: vídeo horizontal 16:9, 30–40 s, pt-BR, com narração do agente WORK, legendas e música/efeitos locais gratuitos. Sem avatar pago e sem dados fictícios.

## 1. O resultado primeiro — recomendado

- **Dispositivo:** resultado real criado pelo Myn.
- **Forma:** cadeia objeto → objeto; a saída puxa a câmera para dentro da API.
- **Primeiros 2 s:** uma imagem real gerada pelo Myn ocupa a tela; a marca d'água some e o texto “gerado sem chave” aparece.
- **Beats:** resultado → requisição real `POST /v1/agent` → geração de mídia → WORK apresenta o produto → cartão final.
- **Look:** UI real do Myn, papel/tinta da marca, azul como única cor de foco.
- **Som:** batida seca, cliques de interface e voz WORK em português.

## 2. O vendedor que sabe

- **Dispositivo:** WORK como vendedor/agente que conhece o produto.
- **Forma:** tomada contínua entre personagem, painel e resultado.
- **Primeiros 2 s:** WORK abre o olho e diz: “Se você tem uma aba, você tem um agente.”
- **Beats:** apresentação → chave mascarada → chamada real da API → texto/imagem/voz gerados → prova de uso → CTA.
- **Look:** WORK de um lado, interface real do outro; recortes de papel e sombra dura.
- **Som:** voz próxima, UI respondendo e trilha minimalista.

## Escolhida: 2 + 3 — O vendedor que sabe, da pergunta à prova

WORK apresenta o produto como vendedor especialista. Uma pergunta real vira texto, imagem e voz; a câmera acompanha a transformação e volta para o agente que conhece cada etapa.

## 3. Uma pergunta, três provas

- **Dispositivo:** uma pergunta real viaja da API até a mídia.
- **Forma:** zoom contínuo prompt → resposta → imagem → áudio.
- **Primeiros 2 s:** o prompt “Crie uma campanha para o Myn” é enviado; o cursor provoca a resposta.
- **Beats:** prompt → HTTP 200 → texto → imagem → narração → WORK resume o que sabe vender.
- **Look:** terminal/API real, tipografia grande e enquadramentos de close.
- **Som:** teclado, confirmação da API e voz do agente.
